# 首图图片读取与素材选择可见性修复

> 2026-10-22 用户真机三张截图反馈，用户已确认按方案修复。上游：00-222、00-242、00-260。

## 1. 问题与范围

- 真机首页模板显示“图片不可用”；首图页模板与已选首图加载失败。
- 主素材库照片存在，“更换首图 → 从素材库选择”却看不到照片。
- 已复现固定 dev 首图页三张模板失败。首页的新清洗/downloadFile 链路未覆盖首图页；选择页默认 categoryCode=portrait，首图入口只提供四个分类。
- 真机首页截图为“图片不可用”，固定 dev 与 10-20 Candidate 已为“图片暂不可用 / 重新加载”，存在前端版本差异证据；未取得真机版本号，不直接认定旧包是唯一原因。

## 2. 验收标准

1. 首图页图库、模板/历史来源的当前首图只下载首个合法 HTTPS 图片地址，清洗异常后缀后以临时文件渲染；素材绑定保持素材库已验证的现签原生图片预览。缩略失败回退原图，失败可重试。
2. 显示临时文件不改变持久化身份：模板保存清洗后的稳定 URL，素材只保存 assetId；不持久化 tempFilePath 或短时签名。
3. 旧请求与旧图片 error 不得覆盖新风格、新首图、已卸载页面；失败只影响对应图片。
4. 首图素材选择默认“全部照片”，不发送分类条件；可筛选已有七类照片，并允许历史/未分类 ready 照片显示、单选与返回。所有权、photo、ready、单选门禁保留。
5. 不更改生活照、剧照、视频、PDF 等其他用途的默认筛选与数量限制；不改用户已有素材分类。
6. 补实际 Vue 页面脚本行为回归，完成 type-check、固定 dev 构建、运行截图、单入口/包体/steering 核验。真机验收与前端版本核对单独记录，不以模拟器代替。

## 3. 发版兼容

仅前端兼容修复；现有 API/请求结构、后端、DDL/DML、COS ACL 不变。测试后端已含 00-260 私有签名修复，不重复部署。用户后续明确授权上传新的测试体验包并替换体验版；仅上传冻结 mini-program-test，不上传 release、不发布正式小程序。新 Candidate 需重新冻结，不能把修改后的 dev 认作原 Candidate。
