# 00-187 当前阶段小程序提审登录门禁整改

## 1. 概述

`2026-07-01` 微信小程序「开拍了演员卡」版本审核未通过，审核反馈集中在登录与首屏授权体验：

1. 登录页面或调用手机号快速验证组件的前置页面存在混淆腾讯官方的元素，包括“微信”字样、微信官方 logo 等。
2. 小程序进入首页后，未浏览体验功能服务即要求授权手机号码、头像、昵称进行授权登录。
3. 登录功能点击无响应，无法完整体验。

本 Spec 负责按审核意见收口小程序登录门禁：登录页移除官方混淆元素，并在复审包中不再暴露手机号快速验证入口；首页允许未登录用户先浏览基础功能，登录 CTA 在未勾选协议、配置不可用或登录失败时都必须给出明确反馈。

## 2. 用户故事

作为审核人员，我进入小程序首页时可以先浏览风格分馆、操作指南等基础内容，不会立即被拉到授权手机号页面。

作为未登录用户，我可以在想创建卡片、查看个人数据或进入需要账号的功能时再主动选择登录。

作为小程序用户，我点击登录页按钮时能获得明确响应：未同意协议时提示确认，授权失败时提示原因，配置不可用时提示使用验证码登录。

## 3. 功能需求

### 3.1 登录页去官方混淆元素

**描述**：登录页不得在手机号授权按钮及其前置文案中展示微信官方 logo、微信品牌字样或可能误导用户认为由腾讯官方背书的元素。复审包采用更保守策略：登录页不暴露 `getPhoneNumber` 手机号快速验证入口，只保留短信验证码登录路径。

**验收标准**：

- WHEN 用户打开 `pages/login/index` THEN 页面不展示 `getPhoneNumber` 手机号快速验证按钮。
- WHEN 用户打开 `pages/login/index` THEN 登录页不展示微信官方 logo 图标。
- WHEN 构建 `mp-weixin` 产物 THEN `pages/login/index.wxml` 不包含 `wechat-login.png` 对应 image 节点。
- WHEN 登录页展示错误 THEN 文案不得使用「微信登录失败」等品牌化描述，应使用短信验证码登录相关自有能力描述。

### 3.2 首页允许未登录浏览

**描述**：`pages/home/index` 作为首页首屏，不得在未登录时自动跳转登录页或自动触发手机号授权。未登录用户可以看到首页 hero、风格分馆基础模板、操作指南和登录引导。

**验收标准**：

- WHEN 未登录用户进入 `pages/home/index` THEN 不调用 `goLogin()` / `reLaunch('/pages/login/index')`。
- WHEN 未登录用户进入首页 THEN 页面展示基础风格分馆或可浏览空态，不展示会话错误 toast。
- WHEN 未登录用户点击「我的数据」「开始创建分享页」「AI生成分享图」等账号相关入口 THEN 再跳转登录页。
- WHEN 已登录演员用户进入首页 THEN 继续同步实名、邀请、等级和我的卡片数据。
- WHEN 已登录剧组用户进入首页 THEN 继续展示移动端分享主线不适用的引导。

### 3.3 登录按钮必须有明确响应

**描述**：登录页的短信登录按钮不得出现点击无响应。按钮即使处于不可提交状态，也要在点击后给出可理解提示。

**验收标准**：

- WHEN 登录页渲染 THEN 不存在手机号快速验证入口，用户只能主动使用验证码登录。
- WHEN 短信登录信息不完整 THEN 点击「登录 / 注册」提示补齐手机号、验证码或协议。
- WHEN 短信登录返回 token/user 成功 THEN 页面先跳转首页，不得因实名、邀请、等级等运行态同步失败而停留登录页。
- WHEN 登录后运行态同步失败 THEN 可给出轻提示，但不得覆盖已保存的登录态或阻断首页跳转。
- WHEN 登录后运行态同步接口返回 401 THEN 不得通过全局请求拦截器 `reLaunch('/pages/login/index')` 抢占已完成的首页跳转。

### 3.4 验收脚本固化

**描述**：新增静态验收脚本，覆盖本次拒审三项的代码与构建产物检查。

**验收标准**：

- WHEN 当前代码仍存在登录页官方 logo THEN 脚本失败。
- WHEN 首页仍通过 `ensureUserSessionReady()` 未登录自动跳登录 THEN 脚本失败。
- WHEN 登录成功导航仍等待 `syncActorRuntimeState()` 后才执行 THEN 脚本失败。
- WHEN 登录后的运行态同步仍允许 401 自动重启到登录页 THEN 脚本失败。
- WHEN 构建产物仍包含登录页官方 logo image THEN 脚本失败。
- WHEN 整改完成并重新构建 THEN 脚本通过。

## 4. 非功能需求

- 不要求删除后端微信手机号授权接口；本轮只调整小程序可见层和触发时机。
- 不删除短信验证码登录；短信登录作为登录页普通入口继续保留。
- 不新增 mock 登录。
- 不新增头像、昵称授权入口。
- 不影响已登录用户 session 恢复和登录后进入首页的路径。

## 5. 约束条件

- 本轮优先修改 `kaipai-frontend/src/pages/login/index.vue`、`kaipai-frontend/src/pages/home/index.vue` 与必要的登录文案 helper。
- 首页未登录浏览只能展示已有模板 / 基础引导或静态兜底，不伪造用户卡片、邀请数、等级等个人数据。
- 账号相关深层页面仍可保持登录门禁；本轮只解除首页首屏的强制登录。
- 小程序 UI 修改后必须执行 `npm run build:mp-weixin`，并核对 `dist/build/mp-weixin` 与 `dist/dev/mp-weixin`。
