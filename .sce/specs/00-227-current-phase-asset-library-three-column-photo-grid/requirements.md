# 素材库三列照片网格

> 状态：已完成，并通过源码、build/dev 产物和微信模拟器运行态核验。
>
> 用户裁决：2026-08-20，素材库中的照片按 `04-生活照片.png` 调整为一行三张。

## 1. 概述

当前 `pages/assets/index` 与 `pkg-profile/assets/index` 将照片、视频和 PDF 统一渲染为信息列表。参考图中的生活照片区域使用三列等宽方形图片网格，照片本身是视觉主体。本文定义素材库照片 Tab 的三列网格合同，并保持视频、PDF及既有业务行为不变。

## 2. 用户故事

- 作为用户，我希望素材库中的照片一屏可以浏览更多内容，并能按三列快速比较图片。
- 作为演员资料或演员卡编辑用户，我希望进入素材选择页时看到相同的三列照片布局，且选择状态清晰可辨。
- 作为维护者，我希望本次只改变照片展示结构，不修改素材 API、数据库或上传与选择语义。

## 3. 功能需求

### 3.1 普通素材库照片网格

**验收标准**：

- WHEN `pages/assets/index` 当前类型为 `photo` THEN 照片以三列等宽网格展示。
- WHEN 页面宽度为 `750rpx` THEN 网格左右边距各为 `40rpx`，行列间距均为 `16rpx`，单格约为 `213rpx`。
- WHEN ready 照片已有会话签名地址 THEN 使用 `t-image` 按 1:1 `aspectFill` 展示。
- WHEN 单张照片仍在处理或缩略图失败 THEN 只降级该格的占位与状态，不影响其他图片。
- WHEN 点击照片 THEN 继续执行现有照片预览；WHEN 点击更多按钮 THEN 继续打开重命名、分类和删除 ActionSheet。

### 3.2 资料流程素材选择页

**验收标准**：

- WHEN `pkg-profile/assets/index` 当前类型为 `photo` THEN 使用与普通素材库相同的三列尺寸与间距。
- WHEN 页面处于选择模式 THEN 每个照片格保留可见的选中覆盖层和不可用状态，点击仍遵循既有选择上限与 ready 门禁。
- WHEN 页面不处于选择模式 THEN 每个照片格保留更多操作入口。
- WHEN 当前类型为 `video` 或 `pdf` THEN 继续使用现有信息列表，不改文件名、状态、重试和操作布局。

### 3.3 状态与分页

**验收标准**：

- 网格改造不得影响上传、取消选择静默、签名 URL 会话缓存、下拉/触底分页和处理状态轮询。
- 空态、首屏加载、页面错误、上传重试和 PDF 重试仍由当前页面状态渲染。
- 每页数量和后端请求参数保持不变。

## 4. 非功能需求

- 图片格使用稳定的三列网格和 1:1 比例，异步加载、状态图标和覆盖按钮不得引发布局跳动。
- 交互覆盖层点击区不小于 `52rpx`，并与图片预览点击互斥。
- `src`、`dist/build/mp-weixin`、`dist/dev/mp-weixin` 三侧均须存在照片网格结构和目标 WXSS 值。
- 微信开发者工具核验继续遵守桌面非干扰规则，只使用项目内部自动化接口。
