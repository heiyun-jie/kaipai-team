# Photo 上传 10MB 试用

## 1. 概述

当前演员作品图与 AI 分析图共用 `photo` 上传类型。`05-15` 新增 AI 生成分享图必填分析图后，用户需要上传更高清的分析源图，现有 5MB 上限偏保守。本 Spec 将 `photo` 图片上传上限试放到 10MB，并保持头像、营业执照、PDF、视频等其他上传类型既有限制不变。

## 2. 用户故事

- 作为演员，我希望上传更高清的作品图或 AI 分析图，避免 5MB 限制阻断可用图片。
- 作为系统维护者，我希望前端预校验、后端强校验与接口说明保持一致，避免前端允许但后端拒绝的体验断层。

## 3. 功能需求

### 3.1 Photo 图片上传上限调整为 10MB

**描述**: 前端 `photo` 上传类型和后端 `photo` 图片上传类型统一从 5MB 调整为 10MB。

**验收标准**: WHEN 用户选择 `photo` 类型图片上传 THEN 前端本地大小校验上限为 10MB。

**验收标准**: WHEN 后端收到 `/file/upload/photo` 上传请求 THEN 后端 `photo` 文件大小校验上限为 10MB。

### 3.2 上传错误文案与接口说明同步

**描述**: 所有面向用户或接口文档的 `photo` 体积说明同步为 10MB。

**验收标准**: WHEN `photo` 图片超过限制 THEN 前端提示文案为 `作品图片不能超过10MB`。

**验收标准**: WHEN 查看后端上传接口说明 THEN `/upload/photo` 描述为每张建议不超过 10MB。

### 3.3 其他上传类型不变

**描述**: 本次试用只调整 `photo`。头像、营业执照、PDF、视频限制不随本次改动变化。

**验收标准**: WHEN 检查上传限制 THEN `avatar` 仍为 2MB，`license` 仍为 5MB，`pdf` 仍为 20MB，`video` 仍为 100MB。

## 4. 非功能需求

- 前后端限制必须同时修改，禁止只放开前端。
- 变更必须通过静态验收脚本验证，覆盖前端、后端与接口文档说明。
- 小程序前端修改后必须执行 `npm run build:mp-weixin`，确认 `dist/dev/mp-weixin` 同步完成。

## 5. 约束条件

- 本次不新增独立 `analysis` 上传类型。
- 本次不修改头像、营业执照、PDF、视频限制。
- Spring Boot multipart 总上限当前为 100MB，已能覆盖 10MB `photo`，本次不调整全局 multipart 配置。
