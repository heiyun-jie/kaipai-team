# 00-151 actor-card 三步流程与底部栏层级修正需求

## 目标

修复用户 2026-04-27 对 `pkg-card/actor-card/index` 的验收问题：

- 页面显示三步流程时，不能在第 2 步就出现保存配置动作。
- 底部按钮栏层级必须高于页面内容，不能被内容遮盖或透出内容干扰阅读。

## 范围

- 小程序页面 `pkg-card/actor-card/index`。
- 通用底部操作栏 `KpBottomActionBar` 的固定层级。
- 小程序构建产物 `dist/build/mp-weixin` 与 `dist/dev/mp-weixin`。

## 禁止项

- 禁止只改文案，不修实际按钮流程。
- 禁止在第 1/2 步触发保存。
- 禁止让底部栏继续使用半透明背景导致内容穿透。
- 禁止未通过类型检查和构建就标记完成。

## 验收标准

- `actor-card` 编辑态明确显示 3 步：卡片预览、快速调节、内容配置。
- 第 1 步主按钮为进入快速调节。
- 第 2 步主按钮为进入内容配置。
- 第 3 步主按钮才是保存分享配置。
- 第 3 步保留公开预览入口，公开预览前仍按现有逻辑保存当前配置。
- 底部操作栏 `z-index` 高于页面内容，背景不透明。
- `npm run type-check`、`npm run build:mp-weixin`、`npm run audit:mp-package` 通过。

## 审查评分

- 三步流程状态正确：35 分。
- 第 1/2 步不触发保存：20 分。
- 底部栏层级和背景遮盖正确：20 分。
- 构建产物同步到 `dist/dev/mp-weixin`：10 分。
- 类型检查和包体审查：10 分。

内部评分低于 95 分必须继续修改，不能收尾。
