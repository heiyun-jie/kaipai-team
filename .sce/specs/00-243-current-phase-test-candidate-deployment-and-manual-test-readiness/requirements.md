## 3. 功能需求

### 3.1 重冻可复现候选

**验收标准**：

- WHEN 候选生成 THEN 源码由提交加显式 overlay 重建，四类产物均有 SHA256/目录树证明。
- WHEN 扫描测试小程序 THEN 只包含 `https://test-api.kplyyk.com`，不包含正式或本地 API。
- WHEN 候选输入变化 THEN 旧候选立即失效并重新生成。

### 3.2 只发布测试运行时

**验收标准**：

- WHEN 发布后端 THEN 只重建 `kaipai-backend-test:18080`。
- WHEN 发布管理端 THEN 只更新 `/opt/kaipai/nginx/html-test`。
- WHEN 发布前后回读正式容器 THEN ID、启动时间和重启次数完全一致。
- WHEN 发布失败 THEN 保持生产不变并输出可诊断的失败证据。

### 3.3 修复严格模式部署缺陷

**验收标准**：

- WHEN 从生产 COS bucket 提取 AppID THEN 必须在 bucket 正则匹配后立即保存捕获值。
- WHEN 随后校验微信 AppID THEN 不得覆盖后续仍需使用的 COS 捕获值。
- WHEN 执行脚本测试 THEN Bash 语法和捕获顺序回归门禁均通过。

### 3.4 切换测试小程序

**验收标准**：

- WHEN 测试产物就绪 THEN 固定测试工程获得候选 `mini-program-test` 的完整文件集。
- WHEN 微信开发者工具仍运行 THEN 不结束、不置顶、不抢焦点；采用不干扰的产物切换方式。
- WHEN 比对文件清单 THEN 文件数、总字节和目录树哈希与候选一致。
- WHEN 文件切换完成 THEN 固定工程的项目级编译缓存必须重建，测试 API 命中大于 `0`，本地和正式 API 命中均为 `0`。
- WHEN 编译缓存仍包含本地或正式 API THEN 状态必须为 `RUNTIME_NOT_SWITCHED`，不得开始人工验收。

### 3.5 输出人工测试入口

**验收标准**：

- WHEN 公网 smoke 完成 THEN 测试 API、测试后台和正式 API 均返回成功。
- WHEN 双环境预检完成 THEN test/prod DB、Redis、端口和容器隔离证明通过。
- WHEN 交付用户 THEN `00-236` 标记为等待人工验收，正式发布仍为未授权。

## 4. 非功能需求

- 不记录或输出任何密钥值。
- 不操作生产数据库迁移、生产 Nginx 路由或正式小程序上传。
- 全程遵守桌面非干扰规则。

## 5. 约束条件

- 本轮只到人工测试可开始，不进入 `00-237`。
- 候选代码、迁移、配置或测试产物再次变化时，本轮验收计数失效。
