# AI 资料册视觉接缝与封面遮罩修复 Requirements

> 状态：已被 `00-171-current-phase-ai-profile-card-single-cover-theme-flow` 取代。新方案移除三页接缝问题，不再维护 `resume / gallery` AI 背景页接续。

## 1. 概述

`00-169` 已经把三页 AI 资料册的连续性参考带、中文 prompt 契约和页面级元数据落到了后端链路。但当前人工截图审查发现三个具体视觉问题：

1. 封面左上角存在大块浅色遮罩，遮盖生成背景。
2. 封面右下角存在白色空白/渐变遮挡。
3. `resume`、`gallery` 并没有稳定沿用上一页底部约 15% 的视觉内容继续往下展开。

本 spec 是 `00-169` 的执行修复层，不重新定义三页结构，不改变小程序前端架构边界，不把后台配置或任意页数引入本需求。

## 2. 用户故事

### 2.1 浏览者

作为演员资料页的浏览者，我希望三页长图在滚动时像同一组连续资料册，而不是每一页突然换背景或出现白块遮挡。

### 2.2 运营与审核

作为审核生成效果的人，我希望封面背景不要被非必要白色块遮住，也希望能通过截图确认 `cover -> resume -> gallery` 的接缝是否真实连续。

### 2.3 研发与测试

作为实现和验证该链路的人，我希望连续性不是只靠 prompt 表述，而是有确定性的页面渲染或合成策略兜底，能用截图和裁切图复核。

## 3. 功能需求

### 3.1 封面左上角不得出现大块遮罩

**描述**：封面标题信息区域不得再通过大面积浅色遮罩覆盖背景。

**验收标准**：

1. WHEN 封面存在 `generatedImageUrl` THEN 页面不得渲染明显大块的 `cover-identity-shield` 类白色背景遮罩。
2. WHEN 标题文字需要可读性 THEN 应使用已有全局 tone、文字阴影或轻量渐变，而不是固定矩形/圆角白块盖住背景。
3. WHEN 截图验证封面顶部区域 THEN 左上标题区后方应能看到生成背景的自然纹理，不应出现突兀白色盖板。

### 3.2 封面右下角不得出现白色空白遮挡

**描述**：封面右下角原本用于遮挡 provider 水印的白色渐变不应无条件显示。

**验收标准**：

1. WHEN provider 输出图没有需要遮挡的水印 THEN 页面不得渲染右下角固定白色遮挡层。
2. WHEN 仍需要处理水印 THEN 必须通过 provider 侧禁用、重新生成、或可审计的条件策略处理，不得默认覆盖真实背景。
3. WHEN 截图验证封面底部区域 THEN 右下角不应出现与原图不连续的纯白/浅色空白块。

### 3.3 下一页顶部必须确定性沿用上一页底部 15%

**描述**：`resume` 顶部必须沿用 `cover` 底部约 15%；`gallery` 顶部必须沿用 `resume` 底部约 15%。该要求不能只依赖模型是否听从 prompt。

**验收标准**：

1. WHEN `resume` 渲染 THEN 顶部接续带必须来自 `cover` 的底部参考带，比例与后端 `continuityBandRatio` 一致，默认约 15%。
2. WHEN `gallery` 渲染 THEN 顶部接续带必须来自 `resume` 的底部参考带，比例与后端 `continuityBandRatio` 一致。
3. WHEN 当前页同时有生成图和连续性参考图 THEN 页面应先展示连续性参考带，再在下方展示当前页背景，并使用轻量过渡避免 15% 位置产生硬断层。
4. WHEN 连续性参考图缺失 THEN 页面可降级为仅展示当前页背景，但必须保留可观测的降级状态或测试日志。
5. WHEN 截图比对接缝 THEN 上一页底部和下一页顶部应肉眼一致或自然过渡，不应突然从人物/竹林跳到空白墙面。

### 3.4 生图 prompt 必须强化“过渡带”职责

**描述**：模型仍需尽量生成更容易接续的原图，尤其是上一页底部 15% 应是干净的背景过渡带。

**验收标准**：

1. WHEN 生成 `cover` THEN prompt 必须要求底部约 15% 为干净、低细节、无人物身体、无衣料主体、无文字、无 UI 的可延展背景。
2. WHEN 生成 `resume` 或 `gallery` THEN prompt 必须要求顶部约 15% 接近上一页参考带的形状、色彩、光线、纹理和空间方向，而不是只保持同风格。
3. WHEN 生成 `resume` 或 `gallery` THEN 仍不得生成可读文字、Logo、二维码、卡片、缩略图框或业务信息。
4. WHEN provider 支持参考图 THEN 继续使用上一页底部裁片作为参考输入。

### 3.5 页面数据必须携带连续性参考信息

**描述**：小程序详情页需要拿到每页的连续性参考 URL 和比例，才能确定性渲染接续带。

**验收标准**：

1. WHEN 后端返回三页 album pages THEN 每个非 cover 页应包含 `continuityReferenceUrl`、`continuityBandRatio`、`continuityReferenceSourcePageType`、`continuityReferenceSourcePageNo`。
2. WHEN 字段为空 THEN 前端不得报错，必须降级为当前页背景。
3. WHEN 真实任务只有一张背景图 THEN 测试必须明确报出 page 2/3 `generatedImageUrl` 缺失，而不是误判为连续性失败。

### 3.6 测试必须包含截图证据

**描述**：本需求以视觉问题为主，必须用截图和裁切图验证。

**验收标准**：

1. 必须生成封面首屏截图，证明左上白块和右下白块已消失。
2. 必须生成 `cover` 底部与 `resume` 顶部接缝截图或裁切对比图。
3. 必须生成 `resume` 底部与 `gallery` 顶部接缝截图或裁切对比图。
4. 必须保存测试结果 JSON，包含每页背景图数量、连续性参考图数量、截图路径和异常日志。

## 4. 非功能需求

1. 不得改变固定三页：`cover / resume / gallery`。
2. 不得让图片模型绘制真实业务文字。
3. 不得把 `SecretKey.csv`、本地输出目录或临时日志提交到仓库。
4. 不得通过 OCR 作为主路径控制 prompt。
5. 页面渲染方案必须兼容 H5 与小程序构建。
6. 截图验证必须使用本地 5100 后端或明确标注 mock 数据来源。

## 5. 非目标

1. 不实现任意页数长图。
2. 不重做资料页的信息卡片布局。
3. 不新增后台配置项。
4. 不把三页合成一张物理超长图片作为本轮必做。
5. 不处理厂商账号注册或密钥配置。

## 6. 验收总则

1. 封面不能再出现大块白色遮盖。
2. 右下角不能再出现无条件白色遮挡。
3. `resume` 顶部必须确定性使用 `cover` 底部参考带。
4. `gallery` 顶部必须确定性使用 `resume` 底部参考带。
5. prompt、页面数据和截图证据必须能解释每一次接续成功或失败。
