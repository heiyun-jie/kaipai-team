# 00-154 需求

## 目标

修正 `pkg-card/card-list/index` 创建分享页流程，使顶部 `01 / 02 / 03` 成为真实步骤，而不是装饰性进度。

## 问题

- 当前页面同时展示 `STEP 01`、`STEP 02`、`STEP 03` 三个区域。
- 底部 `下一步` 直接创建或进入 `actor-card` 预览页。
- 用户看到顶部 `01 / 02 / 03`，但没有按步骤推进，操作流程错误。

## 验收标准

- `01` 只展示选择风格。
- `02` 只展示上传作品。
- `03` 展示命名、分享形式和预览/保存确认。
- 点击 `01` 的下一步只能进入 `02`。
- 点击 `02` 的下一步只能进入 `03`，且没有作品时停留在 `02` 并提示上传。
- 只有在 `03` 点击保存/预览动作时，才创建或进入 `actor-card` 预览页。
- 顶部 `01 / 02 / 03` 必须体现当前步骤和已完成步骤。
- 不恢复旧配置化分享页，不引入 `actor-card` 二次三步配置。
- 修改后必须通过类型检查、小程序构建、包体审查和源码/产物审查。
