# AI 生成分享图分析图必填上传 Requirements

> 状态：执行中 | 优先级：P0 | 依赖：05-05、00-68、AI Profile Card Agent Contract

## 1. 概述

`pkg-card/ai-profile-card/index` 当前只要求用户选择风格即可提交 AI 生成分享图。用户最新要求是在该页面单独增加“上传图片”能力：上传的图片是 AI 生图前用于分析的源图，且必须上传后才能生成；AI 生成后的图片仍作为 AI 图详情中的第一张主图。

本 Spec 只处理小程序生成入口的 UI、上传和提交参数，不改变 AI 图详情页的主图排序、不新增后端生成能力。

## 2. 用户故事

- 作为演员，我希望在生成 AI 分享图前上传一张用于 AI 分析的照片，让生成图更贴近我本人。
- 作为演员，我希望页面明确告诉我：上传图是分析图，生成后的 AI 图才是 AI 图详情首图。
- 作为平台维护者，我希望前端生成请求明确携带 `sourceImageUrl`，而不是继续依赖后端从个人档案里猜第一张图。

## 3. 功能需求

### 3.1 独立上传分析图模块

**描述**：在 `AI生成分享图` 页面中，在 `选择风格` 面板后新增独立的分析图上传模块。

**验收标准**：

1. WHEN 页面加载成功 THEN 用户能看到独立的 `STEP 02 上传分析图` 模块。
2. WHEN 尚未上传图片 THEN 模块展示上传占位、用途说明和“必填”状态。
3. WHEN 上传成功 THEN 模块展示图片缩略图、已上传状态，并提供“更换图片”与“移除”操作。
4. WHEN 用户移除图片 THEN 页面回到未上传状态。

### 3.2 分析图必填生成门禁

**描述**：`一键生成` 必须在分析图上传成功后才能提交生成请求。

**验收标准**：

1. WHEN 用户未上传分析图并点击 `一键生成` THEN 页面提示 `请先上传分析图`，且不调用生成接口。
2. WHEN 用户上传分析图后点击 `一键生成` THEN 生成请求携带该图片 URL 作为 `sourceImageUrl`。
3. WHEN 图片上传成功 THEN 前端必须把该图片同步写入演员档案照片池，使其满足后端 `sourceImageUrl` 候选图校验。
4. WHEN 图片上传中 THEN 生成入口不得提交，页面提示等待上传完成。
5. WHEN 当前风格未解锁 THEN 原有风格锁定提示仍优先成立。
6. WHEN 当前用户尚未建立演员档案 THEN 上传入口提示 `请先完善演员档案后再上传分析图`，不得用空字段创建半成品档案。

### 3.3 AI 图详情首图语义保持

**描述**：上传图片只作为 AI 分析源图，不改变结果页第一张图语义。

**验收标准**：

1. WHEN 生成任务成功 THEN 后端仍按既有链路把 AI 生成图写入分享卡配置的第一张高亮图。
2. WHEN 前端提交 `sourceImageUrl` THEN 不在前端把上传图标记为 AI 图详情首图。
3. WHEN 页面说明上传图用途 THEN 文案必须明确 `生成后的 AI 图会作为详情首图`。

## 4. 非功能需求

1. 复用现有 `chooseImageFiles` 与 `uploadImage`，不新增上传 API。
2. 上传图片继续走 `photo` 业务类型与现有文件大小限制。
3. 页面改动限定在 `pkg-card/ai-profile-card/index.vue` 及必要文档 / 验证脚本；允许复用既有演员档案保存 API，把上传图写入档案照片池。
4. 生成页仍保持当前浅色卡片、固定底部操作栏和卡片间距节奏。

## 5. 约束条件

1. 后端已存在 `AiProfileCardGenerateReqDTO.sourceImageUrl` 与 provider 侧承接，本轮不扩展后端合同。
2. 当前后端 `resolveSourceImage(...)` 会校验 `sourceImageUrl` 必须存在于当前个人档案候选图中；因此前端上传成功后必须同步更新演员档案照片池。
3. 不改变 `ai-profile-card-detail` 的展示排序和分享逻辑。

## 6. 验收总则

1. 新 Spec 已登记。
2. 页面新增必填分析图上传模块。
3. 未上传时无法提交生成。
4. 上传后生成请求携带 `sourceImageUrl`。
5. `type-check`、`build:mp-weixin` 与产物检查通过。
