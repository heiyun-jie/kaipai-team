# 素材库游客态与错误边界收口

> 状态：实施中。
>
> 上游：`00-207`、`00-222`、`00-226`、`00-252`、`00-256`、`00-257`。

## 1. 概述

手机体验版未登录进入 `pages/assets/index` 时，页面无条件请求素材 API，并把微信客户端返回的 `request:fail url not in domain list` 原文渲染给用户。该行为同时违反游客请求边界和用户错误文案边界。本 Spec 将素材库游客态收口为本地会话先判定、零业务请求、明确登录引导。

## 2. 用户故事

- 作为未登录访客，我希望素材库明确显示未登录状态和登录入口，而不是看到后端或微信 SDK 报错。
- 作为已登录用户，我希望素材库继续保留照片、视频、PDF 的加载、上传和管理能力。
- 作为测试负责人，我希望游客态不依赖测试域名是否已加入微信白名单，且不能用隐藏报错替代合法域名修复。

## 3. 功能需求

### 3.1 游客事实源

- 游客判定必须使用 `!userStore.hasStoredSession`，与 Tab 页既有会话合同一致。
- 页面 `onShow` 必须先判定游客；游客不得调用 `getActorAssets`、素材签名、轮询或上传 API。
- 用户从登录态退出后回到仍驻留的素材 Tab，必须清空旧素材、预览 URL、加载/上传反馈和轮询任务。

### 3.2 未登录视图

- 游客必须看到标题“未登录”、说明文案和“去登录”按钮。
- “去登录”跳转 `/pages/login/index`；跳转失败使用用户文案，不暴露平台错误。
- 顶部照片/视频/PDF Tab 和页面导航结构保持稳定；游客点击上传按钮时先进入登录页，不打开系统文件选择器。

### 3.3 已登录行为

- 已登录用户进入页面时继续加载当前素材类型，分页、轮询、预览、重命名、分类、删除、上传和 PDF 处理保持不变。
- 已登录素材列表加载失败时只显示“素材读取失败，请稍后重试”，不得把微信 SDK、URL、堆栈或后端内部错误原文渲染到页面。
- 已登录状态恢复后重新进入素材 Tab，应自动退出游客视图并加载素材。

### 3.4 域名修复边界

- 本 Spec 不把游客零请求当作 `00-257` 合法域名修复完成。
- 已登录体验版仍需 `https://test-api.kplyyk.com` 的微信服务器域名准入，`00-257` 独立继续。

### 3.5 测试 Candidate

- 前端字节变化后必须冻结新测试 Candidate，并将同一冻结 `mini-program-test` 更新到唯一 `dist/dev/mp-weixin`。
- 体验版上传仍只使用微信开发者工具 CLI，不打开、置顶、聚焦或控制微信开发者工具窗口。
- 新体验版只用于测试，不提交审核、不发布正式版。

## 4. 发版兼容

- 仅修改小程序前端页面状态和文案，不改变 API 请求体、响应体、后端、数据库或生产运行时。
- 旧后端合同保持兼容；当前 Candidate 字节变化后必须重新冻结测试 Candidate，不能沿用旧体验版验收计数。
- 日常构建只写唯一 `dist/dev/mp-weixin`，不恢复 workspace `dist/build` 运行入口。

## 5. 验收标准

- 源码和 `dist/dev` 均存在 `hasStoredSession` 游客门禁及“未登录 / 去登录”视图。
- 静态门禁证明游客分支在任何 `getActorAssets` 调用前返回。
- 未登录运行态进入素材库时业务请求计数为 0，页面不含 `request:fail`、`url not in domain list` 或后端原始错误。
- 已登录回归仍可发起测试 API 请求；该项与 `00-257` 域名准入分别记录。
- type-check、专项门禁、构建、TDesign/三列网格/单入口门禁通过。
- 新 Candidate 与 `dist/dev` 目录树一致后，才能上传新的体验测试版本。
