# 演员卡主视觉与参演作品步骤 UI 澄清

> 状态：已完成（2026-08-28）；步骤页 AI 扩图可见性条款由 `00-245` 取代，后端/历史合同继续保留。
>
> 上游：`00-221`、`00-222`、`00-223`；范围仅为小程序演员卡创建向导步骤 1 与步骤 3。

## 1. 问题

`pkg-actor-card/step-visual/index` 同时展示“背景图”和“首图”，但没有解释两者的用途，容易被理解为两个重复的封面入口。主视觉预览沿用全宽 `3:4` 高图且页面滚动容器缺少稳定高度，固定底部操作栏会遮挡长内容；从下一步返回时导航 loading 也可能残留。

`pkg-actor-card/step-works/index` 在无演艺经历时同时展示空态“去新增作品”、列表尾“添加其他作品”和“已选择 0 部作品”，形成重复入口和无意义计数。

## 2. 功能需求

### 2.1 图片语义

- `backgroundImageUrl` 继续表示演员卡版式背景，只影响版式氛围。
- `sourceImageUrl` 继续表示用户上传或从素材库选择的主视觉原图，并作为 AI 扩图输入。
- `expandedImageUrl` 继续表示 AI 扩图结果。
- 页面文案必须使用“版式背景 / 主视觉原图 / AI 扩图结果”区分三者，不新增字段，不改变保存接口。

### 2.2 主视觉页面

- 版式背景和主视觉原图必须形成可扫描的独立区段，并保留风格 Tab、背景选择、素材库和手机上传；AI 扩图后端/历史合同保留，步骤页可见性由 `00-245` 定义。
- 主视觉原图必须完整展示，不得以 `aspectFill` 裁掉人像主体；预览高度必须受控，不能把固定 CTA 挤出或遮挡。
- 页面根容器和 `scroll-view` 必须形成确定的 flex 高度链，正文底部避让固定 CTA 与安全区。
- 从后续页面返回时必须解除 `navigating` 状态，按钮恢复“下一步”并可再次点击。

### 2.3 参演作品页面

- 无演艺经历时只保留空态内的“去新增作品”主入口。
- 只有真实作品列表存在时，列表尾才展示“添加其他作品”和“已选择 N 部作品”。
- 封面语义继续由首张剧照上的“封面”标签表达，不在空态计数文案中重复。
- 从后续页面返回时必须解除 `navigating` 状态。

## 3. 发布兼容

本次只修改小程序模板、样式、页面状态和静态门禁。不改后端接口、数据库、字段名称、素材绑定 usage、路由或公开演员卡合同；旧草稿与已发布数据继续按原字段读取。
