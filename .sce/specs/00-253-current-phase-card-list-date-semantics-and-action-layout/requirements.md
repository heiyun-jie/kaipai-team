# 名片夹日期语义与操作区布局收口

## 1. 概述

`pages/card-list/index` 当前把 `lastUpdate` 直接格式化为裸 `M/D` 文本，并在同一横向 Flex 中放置封面、信息区和三个纵向操作按钮。截图中的 `9/2` 缺少“发布/更新”语义，右侧操作柱又持续压缩标题与日期区域。

本 Spec 在不改变接口、数据库和路由的前提下，明确已发布卡与草稿卡的日期事实源，并把卡片重排为上层信息区、下层横向操作栏。

## 2. 用户故事

- 作为演员，我希望一眼看懂卡片日期代表发布时间还是更新时间。
- 作为演员，我希望预览、分享、复制创建等操作整齐排列，不挤压卡片名称与日期。
- 作为小屏设备用户，我希望按钮文字不换行，卡片结构保持稳定。

## 3. 功能需求

### 3.1 日期语义

- 已发布卡优先读取 `publishedAt`，为空时回退 `lastUpdate`，显示 `发布于M月D日`。
- 草稿卡读取 `lastUpdate`，显示 `更新于M月D日`。
- 非当前年份显示完整年份，例如 `发布于2025年9月2日`。
- 无效或缺失日期不渲染裸占位，不得继续显示无语义的 `9/2`。

### 3.2 已发布卡布局

- 卡片上层由封面和信息区组成，名称独占一行，日期位于名称下方。
- 已发布 Tab 已提供状态上下文，卡片内不重复显示“已发布”标签。
- 预览、分享、复制创建在卡片底部操作栏横向等分排列。
- 分享保持主操作样式，预览和复制创建保持次操作样式。

### 3.3 草稿卡布局

- 草稿保留完成度进度条和百分比。
- 继续编辑、删除草稿在底部操作栏横向两列排列。
- 删除失败信息进入正常文档流，不覆盖操作按钮。

### 3.4 交互与兼容

- 点击卡片上层仍按当前状态进入预览或继续编辑。
- 操作按钮继续阻止事件冒泡，不重复触发卡片点击。
- 不修改 `ActorCardListItemDTO` 契约、后端接口、数据库、分享路径或删除逻辑。
- 日常测试构建只输出并核验固定 `kaipai-frontend/dist/dev/mp-weixin`。

## 4. 验收标准

- WHEN 已发布卡存在 `publishedAt` THEN 日期显示为带“发布于”前缀的中文日期。
- WHEN 已发布卡缺少 `publishedAt` THEN 使用 `lastUpdate` 作为兼容回退。
- WHEN 草稿卡渲染 THEN 日期显示为带“更新于”前缀的中文日期。
- WHEN 在窄屏设备显示已发布卡 THEN 三个操作横向等宽、文字不换行，标题区不被右侧操作柱压缩。
- WHEN 构建完成 THEN `dist/dev/mp-weixin/pages/card-list/index` 的 WXML/WXSS/JS 包含新结构和日期语义，且 scoped hash 一致。

## 5. 约束

- 遵循 `00-206` §3.11 的名片夹能力契约。
- 遵循 `SHARED_CONVENTIONS.md` 的蓝白 UI、间距和桌面非干扰规则。
- 本轮为前端展示调整，不影响旧后端和已发布公开页。
