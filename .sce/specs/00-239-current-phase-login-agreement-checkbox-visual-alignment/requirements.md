# 登录页协议勾选框视觉对齐

> 状态：实现与运行态核验完成，等待并入下一版冻结候选（2026-08-27）。
>
> 上游：`00-221`、`00-226`；影响路由：`pages/login/index`。

## 1. 问题

登录页底部协议区在未选中状态同时显示页面宿主圆框和 TDesign 内部圆形图标，形成两个相互偏移的圆环。问题只属于控件渲染层，不涉及协议状态、短信登录、一键登录或后端合同。

## 2. 功能需求

### 2.1 单一图标

- 未选中时只允许显示一个圆形边框，不得由组件宿主重复绘制第二个圆框。
- 选中时使用 TDesign 官方 `check-circle-filled` 本地 SVG 和 3.0 品牌蓝，不叠加页面伪图标，也不依赖已裁掉的图标字体。
- 图标视觉尺寸固定为 `32rpx`，协议文案位置不得因选中状态改变。

### 2.2 布局与交互

- 协议行继续居中，图标和文案之间只保留 TDesign 内部的稳定间距。
- `handleAgreementChange`、协议弹窗、短信登录和手机号快捷登录门禁保持原逻辑。
- 《用户协议》和《隐私政策》链接继续独立响应，不能被勾选控件遮挡。

### 2.3 产物一致性

- `src`、`dist/build/mp-weixin`、`dist/dev/mp-weixin` 均包含同一控件配置。
- build/dev 的 WXML、WXSS、JS scope hash 必须一致。
- 固定 DevTools 工程继续指向测试 API，不得回退到本地或正式 API。

## 3. 发布兼容

- 仅修改小程序展示层和静态门禁；后端接口、数据库、登录请求体和响应保持不变。
- 当前人工验收候选因前端字节变化失效，修复验证通过后必须重新冻结测试产物，不能沿用旧 manifest 签收。
