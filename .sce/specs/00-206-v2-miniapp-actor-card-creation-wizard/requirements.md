# v2.0 小程序演员卡创建向导

## 1. 概述

本 Spec 定义 2.0 版本「AI 创建演员卡」完整功能模块，将小程序从演员信息录入工具升级为演员卡智能生成平台。

**完整用户路径**：首页入口 → 7 步创建向导 → AI 生成 → 预览 → 发布 / 草稿（名片夹管理）

**覆盖范围**：首页改版、AI 创建向导（7 步）、AI 生成预览发布链路、名片夹页面、个人中心改版、底部导航变更，前后端全链路。

**上游依赖**：`00-199`（职业资料夹与素材库基础数据）、`00-200`（DeepSeek prompt 治理）

**UI 参考**：`UI图_第一组/01—05` 五张设计稿 + 交互流程 SVG（`kaipai-frontend-interaction-flow(1).svg`）

---

## 2. 用户故事

- 作为演员，我希望通过首页大横幅快速进入演员卡创建，也能一键恢复未完成的草稿
- 作为演员，我希望系统从个人资料和演艺经历自动导入数据，减少重复填写
- 作为演员，我希望从系统背景库选择风格背景，并对首图做 AI 智能扩图
- 作为演员，我希望为每部参演作品选择 1—3 张剧照，第一张自动作封面
- 作为演员，我希望通过名片夹统一管理已发布的演员卡和草稿

---

## 3. 功能需求

### 3.1 首页改版（`pages/home/index`）

**描述**：重构为以「AI 创建演员卡」为核心的功能入口页。

**验收标准**：
- WHEN 演员进入首页 THEN 可见「AI 创建演员卡」大横幅，含「开始创建」蓝色按钮
- WHEN 演员有未完成草稿 THEN 横幅下方展示草稿卡（封面图、名称、草稿标签、进度条百分比、「继续 >」链接）
- WHEN 演员点击风格预览图 THEN 以该风格进入创建流程（步骤 1 默认选中该风格）
- WHEN 演员未登录 THEN 仍可浏览首页内容，操作时触发登录

「模板创建」区：Tab 切换 4 种风格（经典 / 都市 / 古风 / 清新），每种展示 2×2 封面图网格

---

### 3.2 AI 创建演员卡 — 向导 Hub 页

**描述**：7 步流程总览 Hub，显示各步骤完成状态，支持直接跳转任意步骤。

| 步 | 名称      | 必填 | 状态示例                    |
|----|-----------|------|-----------------------------|
| 1  | 主视觉照片 | 是   | 已完成 ✅ / 待完成            |
| 2  | 个人资料   | 是   | 已完成 / 待确认（橙）/ 待完成 |
| 3  | 参演作品   | 是   | N 部作品 / 未添加             |
| 4  | 生活照片   | 否   | N 张 / 0 张                   |
| 5  | 视频简历   | 否   | 已添加 / 未添加               |
| 6  | 附件简历   | 否   | 已添加 / 未添加               |
| 7  | 生成设置   | 是   | 已完成 / 待完成               |

**验收标准**：
- WHEN 进入创建流程 THEN 系统生成 `draftId`，开启实时自动保存（后台静默，不显示 toast）
- WHEN 点击任意步骤 THEN 跳转对应步骤页，顶部进度条同步更新
- WHEN 点击「继续下一项」THEN 跳转下一个未完成步骤
- WHEN 所有必填步骤完成 THEN 底部按钮文案变为「生成演员卡」

---

### 3.3 步骤 1 — 主视觉照片

**描述**：选择风格、背景图、首图，对首图进行 AI 扩图，生成主视觉预览。

**验收标准**：
- WHEN 选择风格 THEN 加载该风格背景库（每种 30—50 张，**不进入**用户素材库）
- WHEN 选择 1 张背景图 + 1 张首图后提交 THEN 调用 AI 扩图，展示原图 / 扩图对比，可重新生成
- WHEN 扩图失败 THEN 保留原图，不清空其他已选内容，可重试或更换首图
- WHEN 更换首图 THEN 必须重新扩图，旧扩图结果失效
- WHEN 步骤完成 THEN 展示主视觉预览（背景图 + 扩图合成效果）

---

### 3.4 步骤 2 — 个人资料

**描述**：从演员个人资料自动读取预填充，用户确认或修改；同步选项默认关闭。

**验收标准**：
- WHEN 进入步骤 2 THEN 自动读取姓名 / 身高 / 城市 / 学校 / 联系方式 / 自我介绍并预填
- WHEN 资料有缺失字段 THEN 显示「去个人资料完善」入口，同时允许仅填写当前演员卡
- WHEN 同步选项关闭（默认）THEN 演员卡内修改**不**覆盖个人资料
- WHEN 用户开启同步选项并保存 THEN 对应字段同步写回个人资料

---

### 3.5 步骤 3 — 参演作品

**描述**：从演艺经历选择参演作品，为每部作品管理剧照（1—3 张，第一张为封面）。

**验收标准**：
- WHEN 进入步骤 3 THEN 默认展示「从演艺经历选择」Tab，列出全部作品
- WHEN 作品有已上传剧照 THEN 自动带入 1—3 张（首张作封面），用户可调整
- WHEN 作品无剧照 THEN 提示从素材库选择或手机上传
- WHEN 某勾选作品剧照数量为 0 THEN 校验不通过，硬阻断进入下一步
- 每部作品最多 3 张剧照，支持排序 / 替换 / 删除；「新增作品」Tab 可直接录入新作品
- WHEN 保存演员卡 THEN 剧照作为快照绑定演员卡，不随演艺经历原始数据变化

---

### 3.6 步骤 4 — 生活照片

**验收标准**：
- WHEN 已选照片超过 12 张 THEN 显示蓝色提示 Banner（软限制，不阻断操作）
- WHEN 长按照片 THEN 可拖拽调整展示顺序
- 支持从素材库选择 / 手机上传；支持单张删除

---

### 3.7 步骤 5 — 视频简历（可选）

- 最多 1 条视频；未添加可直接跳过；支持预览 / 替换 / 删除

### 3.8 步骤 6 — 附件简历（可选）

- 格式：PDF / PPT / PPTX；最多 1 份；未添加可直接跳过；支持预览 / 替换 / 删除

### 3.9 步骤 7 — 生成设置

- 可配置联系方式 / 视频简历 / 附件简历的**展示开关**
- 可**拖拽调整**上述模块的展示顺序

---

### 3.10 生成、预览与发布

**验收标准**：
- WHEN 提交生成前 THEN 校验所有必填步骤（参演作品剧照非空、步骤 1/2/7 已完成），不通过则标记缺失步骤并阻断
- WHEN AI 生成中 THEN 显示进度态，禁止重复提交
- WHEN 生成失败 THEN 保留全部已填数据，可重新生成或修改后再生成
- WHEN 生成成功 THEN 展示完整长页预览（可滚动检查）；预览页支持换背景 / 换首图 / 修改各步骤内容
- WHEN 用户发布 THEN 演员卡进入名片夹「已发布」
- WHEN 用户退出 THEN 保存草稿，进入名片夹「草稿」
- WHEN 已发布演员卡再次编辑并发布 THEN 生成新版本，不影响当前线上页面

---

### 3.11 名片夹页面（底部 Tab 二）

- Tab：「已发布」/「草稿」
- 已发布卡：封面 + 名称 + 发布时间；支持预览 / 分享 / 复制创建
- 草稿卡：封面 + 名称 + 完成进度；支持继续编辑 / 删除

### 3.12 个人中心改版（`pages/mine/index`）

- 资料完整度进度条 + 百分比 + 「继续完善 >」跳转
- 统计数字行：演员卡数量 / 素材数量 / 浏览量
- 「演员资料」分组：个人资料 / 演艺经历 / 自我介绍（三个 List Row 入口）
- 「账户与服务」分组：实名认证 / 帮助与反馈 / 设置

### 3.13 底部导航变更

- 底部 4 个 Tab：**首页 / 名片夹 / 素材库 / 个人**（「名片夹」为新增 Tab）

---

## 4. 非功能需求

- 所有步骤内容实时自动保存（debounce 2s，后台静默）
- 创建向导各步骤页面进入 `pkg-actor-card` 分包，不增加主包体积（遵循 `00-05` 2MB 约束）
- AI 扩图与演员卡生成为异步操作，需有 loading 态、进度提示与超时兜底

## 5. 约束条件

- 演员卡与个人资料、素材库三者相互独立；删除演员卡不删除原始素材
- AI 调用统一由后端封装，前端不直接调用 AI 接口（`00-200` 规则延续）
- 背景图库不进入用户素材库，不出现在素材库页面
- 身份证号只展示脱敏值，前端不持有明文

## 6. 全局规则

① 所有步骤实时自动保存　② 更换背景不清空资料和作品　③ 更换首图必须重新扩图  
④ 当前演员卡修改默认不覆盖个人资料　⑤ 演员卡 / 个人资料 / 素材库相互独立  
⑥ 删除演员卡不删除原始素材　⑦ 发布后编辑生成新版本，不影响线上页面
