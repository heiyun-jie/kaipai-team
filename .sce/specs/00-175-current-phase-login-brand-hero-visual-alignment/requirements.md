# 00-175 当前阶段登录页品牌 Hero 视觉协调

## 1. 概述

`pages/login/index` 当前已经收口为微信一键登录，但顶部品牌 hero 存在视觉不协调问题：顶部未按微信胶囊导航高度预留空间，品牌卡片靠近胶囊；`KAIPAILE / 开拍了` 字距过大，暗色大块与底部登录卡片衔接生硬。

本 Spec 负责优化登录页顶部品牌展示，只调整视觉层级、间距与安全区域，不改变微信登录能力、短信审核门禁和登录流程。

## 2. 用户故事

作为用户，我打开登录页时，顶部品牌区域应当与微信胶囊按钮、登录卡片形成协调的整体，而不是看到一个突兀的大暗色块。

作为产品人员，我希望登录页继续保持只用微信一键登录，同时品牌展示更符合“开拍了”的当前命名。

## 3. 功能需求

### 3.1 顶部安全区域对齐

**描述**：登录页顶部需要按微信胶囊导航区域预留高度，避免品牌 hero 与右上角胶囊按钮发生视觉冲突。

**验收标准**：

- WHEN 用户在微信开发者工具打开 `pages/login/index` THEN 顶部品牌卡片不与右上角胶囊按钮挤在同一视觉层。
- WHEN 构建 H5 390x844 视口核验 THEN 页面无横向溢出。

### 3.2 品牌字距与层级优化

**描述**：品牌 hero 中 `KAIPAILE` 与 `开拍了` 应降低过度字距，形成更紧凑、自然的品牌锁定。

**验收标准**：

- WHEN 用户打开登录页 THEN hero 展示 `KAIPAILE` 与 `开拍了`。
- WHEN 用户打开登录页 THEN `开拍了` 不应显示成过度分散的三个字。
- WHEN 构建产物搜索 THEN 不出现 `KAUPAILE`、`JU MING PIAN` 或 `剧 名 片`。

### 3.3 不改变登录能力

**描述**：本轮仅优化登录页顶部视觉，不恢复短信验证码入口，不改变微信一键登录按钮绑定。

**验收标准**：

- WHEN 构建 `mp-weixin` 产物 THEN 登录页仍不包含手机号验证码登录表单可见文本。
- WHEN 构建 `mp-weixin` 产物 THEN 微信登录按钮仍保留 `getPhoneNumber` 绑定。
- WHEN 本轮修改完成 THEN 不改后端接口、不改登录 Store、不新增 mock。

## 4. 非功能需求

- 不新增装饰填充节点。
- 不恢复手机号验证码登录入口。
- 不改变 `00-173` 微信登录链路。
- 继续复用 `MINI_PROGRAM_BRAND` 品牌配置。
