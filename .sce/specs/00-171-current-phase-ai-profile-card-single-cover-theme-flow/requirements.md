# AI 分享图单封面主题内容流 Requirements

> 状态：当前执行中 | 优先级：最高 | 替代：00-168、00-169、00-170

## 1. 概述

旧三页资料册方案要求一次任务生成 `cover / resume / gallery` 三张背景图，并用连续性参考带处理页间接缝。最新产品方向改为：

1. 一次任务只生成一张 AI 封面背景图。
2. 封面以下不再生成 AI 背景图。
3. 后续资料内容全部使用确定性的主题底色和原生组件继续展示。
4. 页面可以持续追加资料模块，不再受三张图是否接上、是否缺页、是否生成失败的限制。

本需求直接取代旧三页任务合同。新任务不得再把 `resume / gallery` 作为生成目标。

产品口径上，本功能不是“只展示一张图片”的纯单图页，而是“AI 分享详情页”：AI 生成物只包含一张封面背景图，真实资料由小程序原生组件在同一主题底色上继续展示。

## 2. 用户角色与用户故事

### 2.1 角色矩阵

| 角色 | 当前定位 | 本功能权限 | 非权限/边界 |
| --- | --- | --- | --- |
| 演员本人 | 当前小程序主用户，维护档案并生成分享产物 | 可生成 AI 分享图、查看任务、进入作品集、打开详情页、分享详情页、删除自己的 AI 作品 | 不通过本功能编辑档案事实源；删除作品后对应详情页不得继续作为有效分享产物 |
| 外部访客/项目方 | 通过分享链接进入的资料浏览者 | 可打开公开 AI 分享详情页、浏览封面与内容流、申请联系 | 不可生成、编辑、删除 AI 作品；不作为独立剧组端工作台扩展 |
| 未登录访客 | 分享链路中的轻量访问者 | 可在公开参数有效时浏览公开资料 | 触发联系、投递或其他需要身份的动作时按现有登录/授权链路处理 |
| 剧组端账号 | 当前小程序主线外角色 | 不作为本功能扩展目标 | 不新增剧组端筛选、收藏、批量管理或工作台能力 |
| 研发/运营 | 维护成本、质量与失败定位 | 可用任务状态、provider 调用、theme fallback 和日志判断质量 | 不依赖三页接缝修复作为当前验收目标 |

### 2.2 演员用户

作为演员，我希望 AI 分享页第一屏有一张高质量封面图，下面可以稳定展示更多资料，不会因为多张生成图断层影响观感。

### 2.3 浏览者

作为项目方或浏览者，我希望打开分享页先看到封面主视觉，再顺畅向下浏览基础资料、技能、作品、照片和视频，不需要等待多张 AI 图加载。

### 2.4 研发与运营

作为维护者，我希望生成成本、失败定位和页面扩展都收敛到单封面图，后续增加内容模块只改确定性前端，不再依赖图片模型生成更多页面。

## 3. 功能需求

### 3.1 产物定义与访问模型

**描述**：新主路径的 AI 生成物只有一张封面背景图，但用户访问到的是一张包含封面与原生内容流的 AI 分享详情页。

**验收标准**：

1. WHEN 新任务成功 THEN `generatedImageUrl` 是唯一需要持久化和分享的 AI 图片资产。
2. WHEN 前端打开详情页 THEN 首屏展示封面背景图，封面以下内容使用原生组件和主题底色继续渲染。
3. WHEN API 返回 `pages` THEN 该字段只允许作为历史兼容字段存在，主路径不得把它当成新任务合同的一部分。
4. WHEN 用户删除 AI 作品 THEN 新任务成功与否不得再依赖 `actor_ai_profile_card_page` 的页级数据。

### 3.2 单封面生成合同

**描述**：新的 AI 分享图任务只生成一张封面背景图。

**验收标准**：

1. WHEN 用户提交新的 AI 分享图任务 THEN 图片 provider 仅围绕单个 `cover` 目标生成，不得生成 `resume / gallery` 或其他页面目标。
2. WHEN 任务开启质检重试 THEN 任何重试都只能继续生成 `cover`，不得引入页级生成或连续性参考带。
3. WHEN 任务成功 THEN `generatedImageUrl` 指向可直接作为详情页封面的图片，且不得等于原始源图 URL。
4. WHEN 任务返回给前端 THEN 不再要求 `pages` 包含 `cover / resume / gallery`，前端主路径也不得依赖 `pages.length` 判断成功。
5. WHEN 旧三页页面表存在历史数据 THEN 新前端不得把三页渲染作为主路径，历史页只允许作为兼容兜底。

### 3.3 主题底色合同

**描述**：封面以下所有内容使用任务级主题底色和确定性主题 token 渲染。

**验收标准**：

1. WHEN 后端返回任务或作品 THEN 必须返回可用于页面延展的主题信息，至少包含 `backgroundColor`、`surfaceColor`、`surfaceStrongColor`、`accentColor`、`textColor`、`mutedTextColor` 和 `borderColor`。
2. WHEN 前端渲染封面以下内容 THEN 页面背景必须使用任务主题底色，不得依赖第二、第三张 AI 背景图。
3. WHEN 后端返回未知或缺省的 `templateSceneCode / styleCode` THEN 必须落到稳定 fallback theme，不能让页面缺字段破版。
4. WHEN 封面 prompt 生成时 THEN prompt JSON 内的 `flowTheme.backgroundColor` 必须与 API 返回的 `theme.backgroundColor` 保持同一色彩方向。
5. WHEN 内容模块持续增加 THEN 只需要追加确定性 section，不需要新增 AI 生图调用。

### 3.4 封面仍为背景-only

**描述**：唯一生成图仍然只承担视觉背景，不绘制真实业务文本。

**验收标准**：

1. WHEN 调用图片 provider THEN prompt 必须声明生成图是封面背景，不得生成最终姓名、履历、电话、二维码、Logo、标签、按钮、卡片或假 UI。
2. WHEN 前端渲染封面 THEN 姓名、资料、技能、作品、照片、视频入口全部由原生组件确定性覆盖。
3. WHEN 用户资料变化 THEN 页面后续内容读取最新事实源，不依赖图片里被烘焙的旧资料。

### 3.5 后续内容流

**描述**：封面以下改为普通滚动内容流，承载可扩展资料。

**验收标准**：

1. WHEN 用户向下滚动 THEN 可以看到基础资料、形象条件、语言能力、技能特长、拍摄经历、照片和视频等内容。
2. WHEN 某类资料缺失 THEN 对应 section 使用确定性空态或降级文案。
3. WHEN 内容很长 THEN 页面仍然使用同一主题底色自然延展，不出现 AI 图片接缝或缺图空白。
4. WHEN 底部联系/分享操作栏固定显示 THEN 不得遮挡最后一个内容 section。

### 3.6 作品集与分享语义

**描述**：作品集和分享仍以单封面图作为入口资产。

**验收标准**：

1. WHEN 作品集展示 AI 分享图 THEN 卡片封面使用 `generatedImageUrl`。
2. WHEN 用户点击作品集 AI 分享图 THEN 进入新的单封面详情页。
3. WHEN 用户分享详情页 THEN 分享封面使用同一张 `generatedImageUrl`。
4. WHEN 新任务失败 THEN 不得产生只有主题内容、没有封面图的成功作品。

### 3.7 生命周期与兼容边界

**描述**：任务状态、失败态和历史数据的展示规则必须明确，避免把兼容残留误当成新合同。

**验收标准**：

1. WHEN 任务处于 `pending / running` THEN 前端展示加载或占位态，不得伪装成成功详情页。
2. WHEN 任务处于 `failed` THEN 前端展示失败态和重试入口，不得把失败任务当成成功作品分享。
3. WHEN 历史 artifact 带有 `pages` THEN 新详情页只允许用 `generatedImageUrl` 或历史 `cover` 作为兜底封面，不得渲染 `resume / gallery` 页。
4. WHEN API 仍返回 `pages` THEN 该字段必须明确标记为 legacy compat，前端主路径不得用它来判断是否成功。

## 4. 非功能需求

1. 新任务生成目标从三页收敛为单个 `cover`，不再以页级数量定义成功标准。
2. 首屏只加载一张 AI 封面图。
3. 页面后续内容应支持持续追加，不引入固定页数限制。
4. 主题色必须有稳定兜底，避免接口缺字段时页面破版。
5. 旧三页连续性、参考带和接缝截图不再是当前验收目标。
6. 主题文本对比度和按钮可读性必须稳定，不能因为场景色切换导致封面和内容流不可读。

## 5. 约束条件

1. 不得把真实业务文字交给图片模型绘制。
2. 不得继续把 `resume / gallery` 作为新任务的生成目标。
3. 不得把任意页数配置重新引入后台或前端。
4. 不得破坏普通分享卡和作品集入口。
5. 历史三页数据如果仍存在，只能作为迁移期兼容数据，不得成为新主路径。
6. 不得把 `pageType=resume / pageType=gallery / continuity / tail_reference` 作为新任务的成功条件或主渲染条件。
7. 不得把 `gallery` 这类美术命名误当成页面生成语义；内容模块命名可以保留，但页级合同必须收敛到单封面。

## 6. 非目标

1. 不实现图片像素级主色提取；当前可用场景固定主题色映射。
2. 不实现后端长图合成。
3. 不实现多页导出。
4. 不重做演员资料编辑页。
5. 不新增低代码布局编辑器。
6. 不把剧组端账号纳入本功能的新增工作台范围。

## 7. 验收总则

1. 新 AI 分享图任务只生成一张封面背景图。
2. 后端任务/作品响应包含任务级主题 payload。
3. 前端详情页渲染为一张封面 + 统一底色内容流。
4. 前端不再渲染 `resume / gallery` AI 背景页。
5. 相关后端单测、前端类型检查和构建验证通过。
6. 新任务的成功与失败必须在前端状态上清晰可见，不能把兼容残留误读成新主路径。
