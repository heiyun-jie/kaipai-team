# 微信开发者工具本地 MCP 接入

> 状态：实现中。上游：00-216 / 00-219 / 00-223。
>
> 目标：为小程序构建、产物核验和微信开发者工具项目级启动提供一个项目内、受限范围的本地 MCP，不安装未知第三方插件，不开放任意命令执行。

## 1. 概述

当前 UI 回归工作需要重复执行构建、`dist/build` 与 `dist/dev` 同步、scoped hash 核验和微信开发者工具运行态核验。桌面窗口自动化会影响用户正常使用，也容易误操作普通微信或其他窗口。本 Spec 定义一个以 STDIO 运行的 Node MCP 服务，仅调用微信工具自带的 `wechatide` skill CLI，并固定使用 `liteMode` 内部模拟器。

## 2. 用户故事

- 作为开发者，我希望 Codex 可以通过结构化工具启动并核验微信小程序，而不必控制整个桌面。
- 作为验收者，我希望每次运行态检查都能明确说明打开的是 `dist/dev/mp-weixin` 还是其他目录。
- 作为本机用户，我希望工具只影响微信开发者工具项目，不结束普通微信或执行任意系统命令。

## 3. 功能需求

### 3.1 项目级 STDIO MCP

**描述**：服务通过项目 `.codex/config.toml` 注册，使用本机 Node 内置模块运行，不依赖新增 npm 包或远程 MCP。

**验收标准**：WHEN Codex 启动项目 MCP THEN 服务完成 MCP `initialize` 握手并返回工具清单；服务停止后不残留后台进程。

### 3.2 受限微信工具操作

**描述**：服务只允许使用仓库前端目录、`dist/build/mp-weixin`、`dist/dev/mp-weixin` 和已登记的微信 CLI；不得接受任意 shell 命令、任意项目路径或桌面坐标。运行态页面操作通过 `open_project_window(liteMode)`、`simulator_open_page`、`simulator_screenshot`、`automation_*` 和 `get_simulator_console` 完成。

**验收标准**：WHEN 调用启动/退出/自动化工具 THEN 命令参数只能指向固定项目路径；WHEN 调用页面操作 THEN 只能使用登记路由和内部模拟器；WHEN 调用未知工具或非法路由 THEN 返回 MCP 工具错误，不执行系统命令。

### 3.3 构建与三侧产物核验

**描述**：提供构建同步和指定路由的 `src` / `dist/build` / `dist/dev` 产物核验，至少报告目标文件存在性、SHA-256 和 `data-v-*` scoped hash。

**验收标准**：WHEN `build:mp-weixin` 完成 THEN 工具报告退出码、输出摘要和目标目录；WHEN build/dev 三件套不一致 THEN 工具报告失败事实，不宣称运行态已生效。

### 3.4 桌面影响边界

**描述**：默认不结束任何进程；运行态打开、导航、截图和元素操作只通过微信工具内部 API；关闭项目优先使用 `close_project_window`，全局 `quit` 仅保留为用户明确要求的项目级退出操作。

**验收标准**：WHEN 调用状态检查 THEN 只读返回 CLI、项目目录和可识别的微信开发者工具进程信息；WHEN 调用截图 THEN 返回模拟器画面路径而非桌面截图；WHEN 调用关闭/退出 THEN 不执行通用 `Stop-Process` 或宽泛进程名杀进程。

**非干扰规则**：任何 MCP 或手工验证流程都不得将微信开发者工具置顶、强制前台、抢占焦点或覆盖用户正在使用的窗口。若内部 `open_project_window` / `liteMode` 在当前微信工具版本中无法保证不抢焦点，则默认不调用该类开窗工具，改用产物核验、用户提供截图或在用户明确授权的空闲窗口期执行；执行后只关闭固定项目窗口，不影响普通微信和其他桌面应用。

## 4. 非功能需求

- MCP 服务不引入新的运行时依赖，Node 版本满足仓库现有环境。
- 工具输出截断到有限长度，避免把构建日志无限写入 Codex 上下文。
- 构建、打开、退出和页面自动化工具标记为写操作；状态、产物核验、模拟器截图、运行时和 console 标记为只读操作。
- 只允许项目级配置，不修改用户全局 MCP 配置。

## 5. 边界

- 微信工具的内部 skill CLI 需要本机授权；MCP 不绕过授权，也不使用桌面窗口自动化、置顶、抢焦点或桌面坐标控制。
- 页面截图、模拟器内部 DOM 和控制台详情仍以微信工具实际暴露的自动化接口为准；本 MCP 只负责受限调度和产物证据。截图路径限定在 `.sce/evidence/wechat-devtools`。
- 不通过 MCP 传入登录票据、CLI token 或其他敏感凭据；如 CLI 已配置 token，则由本机环境变量读取。
